03 — Projects

Selected Work

End-to-end AI systems built from research to production.

Groundwater Information Retrieval Chatbot

SIH 2024

A document-understanding pipeline that enables context-aware querying of groundwater data. Built for Smart India Hackathon 2024, combining vector search with LLM-powered retrieval for real-time information access.

Architecture

Documents are processed through Google AI Embeddings and stored in a FAISS-based vector store. Queries hit the vector index for context retrieval, which feeds into GROQ Gemma-7B-It for grounded generation via LangChain orchestration.

Challenges & Results

Optimised chunk sizing and embedding strategy to balance retrieval accuracy with latency. Achieved real-time querying with context-aware responses through the Streamlit interface.

Lessons Learned

Learned the critical importance of embedding quality and chunk strategy in RAG systems. Small changes in preprocessing dramatically affect retrieval relevance.

VisionVoice AI — Multimodal Assistant

SIH 2024

A multimodal voice and image assistant that integrates speech-to-text with visual understanding. Accepts voice commands and images simultaneously, generating contextual AI responses.

Architecture

Whisper handles speech-to-text transcription, feeding into LLaVA-1.5-7B for combined text-and-image understanding. The full pipeline runs on GPU with 4-bit quantisation for efficient inference.

Challenges & Results

Memory constraints with 7B parameter models required careful quantisation tuning. Achieved GPU-efficient inference while maintaining response quality through 4-bit optimisation.

Lessons Learned

Model quantisation is a critical skill for deploying large models on constrained hardware. The trade-off between precision and performance requires systematic experimentation.

Ultimate PDF — CLI Toolkit

PyPI Package

A dependency-light Python CLI wrapping pypdf and PyMuPDF behind a unified Typer interface. Published on PyPI and installable via pip — built for developers who work with PDFs daily.

Architecture

Subcommand-based CLI architecture with Typer. Six core operations — merge, split (by range, interval, or page selection), compress, rotate, encrypt/decrypt, and metadata inspection — with per-page targeting and batch output.

Challenges & Results

Designed a clean, intuitive interface that abstracts the complexity of two underlying PDF libraries. Packaged for Python 3.10+ with minimal dependencies.

Lessons Learned

Publishing to PyPI taught me the importance of proper packaging, versioning, and developer-facing documentation. CLI design is its own discipline.

Research Project — 2024

Performance Benchmarking of PyTorch on MPS vs CUDA vs CPU

A comparative study evaluating training and inference performance of PyTorch models across CPU, NVIDIA CUDA GPU, and Apple MPS backends. CNN-based experiments measured training time, accuracy, and power consumption across all three compute environments.

Key finding: demonstrated 6–10× speed improvements with MPS over CPU and analysed MPS as a competitive GPU alternative for macOS-based deep learning workflows.
